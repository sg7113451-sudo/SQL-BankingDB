# 🏨 2. Hotel Booking Analysis

A SQL project created to analyze hotel bookings, customers, rooms, and revenue.

## Database Structure

The project contains **4 main tables**:

### Customers

Stores customer information.

* `customer_id`
* `customer_name`
* `email`
* `phone`
* `country`

### Hotels

Stores hotel information.

* `hotel_id`
* `hotel_name`
* `city`
* `hotel_type`
* `rating`

### Rooms

Stores room information.

* `room_id`
* `hotel_id`
* `room_type`
* `price_per_night`
* `capacity`

### Bookings

Stores booking information.

* `booking_id`
* `customer_id`
* `room_id`
* `check_in`
* `check_out`
* `guests`
* `booking_status`
* `total_amount`

## 🔍 Analysis Questions

Examples of questions solved in this project:

* Find the total number of bookings for each hotel.
* Find the total revenue generated by each hotel.
* Find the total number of guests.
* Display total guests on every row using `SUM() OVER()`.
* Find the highest-revenue hotel.
* Find the average booking amount.
* Find customers with the highest number of bookings.
* Rank hotels based on revenue.
* Calculate running revenue using window functions.

# 📈 Example Window Function

```sql
SELECT 
    loanid,
    customerid,
    loanamount,
    RANK() OVER (
        ORDER BY loanamount DESC
    ) AS loan_rank
FROM loans;
```

This query ranks loans based on their loan amount.
